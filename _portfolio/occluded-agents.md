In mobile robotics and autonomous driving, agent interactions are often modeled as Nash equilibria of noncooperative dynamic games. These methods rely on observations to identify participating agents and therefore struggle when some agents are occluded.

This project develops an occlusion-aware game-theoretic inference method to estimate locations of potentially occluded agents and infer intentions of both visible and occluded agents. We also propose a receding-horizon occlusion-aware contingency planner for safer navigation.
